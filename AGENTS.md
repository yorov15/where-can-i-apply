# Nerio — память проекта для агентов (Codex, DeepSeek Harness, OpenCode)

Nerio (nerio-app.vercel.app) — бесплатный сайт: школьник из Центральной Азии заполняет анкету и видит,
в какие программы обучения за рубежом может подать документы, почему, и что делать до дедлайна.
Хозяин — Мурод. Отвечай по-русски, прямо, коротко, без подбадривания. Пишет часто голосом: слова бывают
искажены — читай смысл, очевидное не переспрашивай.

## Жёсткие правила данных

- Ничего по памяти модели. Каждое поле — дословная цитата из снимка, ссылка, дата, хеш. Нет в тексте —
  пусто / `notMeasured`.
- Оценки (часы подготовки, сроки изготовления документа) — только с пометкой «оценка» и источником.
- Никаких шансов поступления и процентов.
- Новый домен источника одобряет только Мурод; без его «да» в `tools/sources.toml` не писать.
- Нет даты на странице — срок `null`. Порог платного пути ≠ порог пути со стипендией.
- 11-летняя школа при требовании 12 лет — «уточни в приёмной», не отказ.
- Подпись данных: `python -m tools.review <id> --by-assistant`.
- Тексты для людей — коротко, глагол первым, без канцелярита и «AI-стиля»; новых фактов не добавлять.

## Git

- Не коммитить: `.agent-bridge/`, `.mcp.json`, `opencode.jsonc`, `package.json`, `package-lock.json`,
  `.gitignore`, чужие незакоммиченные файлы (в `raw/` и `docs/` лежат неотслеженные файлы — не трогать).
- Сообщения коммитов по-русски, в стиле `git log`: «Маршрут: …», «Сборка: …».
- Пуш: `git fetch --ipv4` → `git rebase origin/main` → `git push --ipv4`. Force push запрещён (робот
  каждый день пишет в `main`). IPv6 на машине не работает — всегда `--ipv4`. Таймаут — повторить.
