# Открытые проекты и платформы для абитуриентов: что взять Nerio

Разбор от 04.11.2026. Дополняет `docs/PLATFORMS.md` (17 сервисов) и `docs/PLAN-V2.md` §2. Сервисы, уже разобранные
там (Common App, UCAS, Scoir, BigFuture, Naviance, CollegeVine, Studyportals, DAAD, uni-assist, Study in Korea, JPSS,
Yocket, Leverage Edu, ApplyBoard, Khan, Magoosh, DET, IELTS Ready, Kollegio, Crimson), здесь не повторяются.

Как собирал и чего не удалось:

- **GitHub.** Поиск через `gh api search/repositories`, 41 запрос. Звёзды и `pushed_at` — по API поиска на 04.11.2026.
  Дату последнего коммита получить не удалось: API репозиториев и коммитов закрыт для этой сессии, поэтому указан
  последний пуш в репозиторий (`pushed_at`). Лицензия — по самому файлу `LICENSE*`, скачанному с
  `raw.githubusercontent.com`, а не по метке GitHub.
- **Платформы.** Главные страницы не открылись: сеть сессии не пускает на `scholarships360.org`, `www.goingmerry.com`,
  `bold.org`, `unibuddy.com`, `www.duolingo.com`, `www.niche.com`, `educationusa.state.gov`, `www.fastweb.com`,
  `apps.apple.com`. Сведения ниже — из веб-поиска по справочным страницам сервисов, страницам вузов и обзорам. Это
  пересказ выдачи, дословность цитат по живой странице не сверена. Fastweb не разобран.
- **Лицензия Nerio.** В репозитории нет файла `LICENSE`, в `package.json` поля `license` нет. Значит, код Nerio
  закрыт по умолчанию. Отсюда правило совместимости в таблице:
  - MIT, ISC, CC0, Apache-2.0 — брать можно, сохранив копирайт и текст лицензии (Apache — ещё `NOTICE` и пометку
    изменений);
  - GPL/AGPL — нельзя, пока Nerio не перейдёт на ту же лицензию;
  - CC BY-NC-ND, CC BY-NC-SA — нельзя: запрет переделок или требование той же лицензии;
  - нет лицензии — только идея, код не копировать;
  - чужие данные под CC BY 4.0 юридически брать можно, но по правилу «только цитата из официального снимка» они
    годятся лишь как список, что проверить.

## 2. Платформы: первый экран, первый шаг, «подходишь / нет», следующее дело

Все главные страницы закрыты сетью сессии (см. начало). Ниже — что видно по справке сервисов и сторонним страницам,
со ссылкой на каждую.

### Going Merry (стипендии США)

- **Ценность.** «Найди стипендии и подавай на них в одном месте»
  ([блог Going Merry](https://goingmerry.com/?p=1596)).
- **Первый шаг.** Профиль; по ответам профиля подбираются стипендии. Справка советует заполнить профиль ближе к 100 %,
  чтобы подбор был точным ([справка](https://support.goingmerry.com/en/articles/2384752-students-how-do-i-get-started-on-going-merry)).
- **Подходишь / нет.** Серая наклейка «Match» на карточке, если профиль совпадает с частью или со всеми условиями
  ([справка](https://support.goingmerry.com/en/articles/2384801-students-how-do-i-apply-for-scholarships)).
- **Следующее дело.** «Пакеты»: несколько стипендий с похожим вопросом эссе — одна заявка и одно эссе
  ([пресс-релиз](https://www.newswire.com/news/students-can-now-apply-for-dozens-of-scholarships-at-a-time-with-one-20815710)).
- Есть приложение в App Store ([ссылка](https://apps.apple.com/us/app/id1483037600)), страница не открылась.

### Bold.org (стипендии США)

- **Ценность.** «Все стипендии Bold.org эксклюзивны, нигде больше на них не подать»
  ([страница для заявителей](https://www.bold.org/applicants/)). Бесплатно.
- **Первый шаг.** Бесплатный профиль, несколько вопросов о себе и целях, затем «Мои совпадения»
  ([справка «My Matches»](https://studenthelp.bold.org/en/articles/13716383-my-matches-how-scholarships-match-to-you)).
- **Подходишь / нет.** Подходящесть считается по профилю. Если совпадений мало, справка прямо называет поля с
  наибольшим влиянием: уровень образования, специальность, год выпуска
  ([справка «Eligibility»](https://studenthelp.bold.org/en/articles/13716385-scholarship-eligibility)).
- **Слабое место.** Подбор только среди своих стипендий
  ([обзор Scholarships360](https://scholarships360.org/financial-aid/bold-org-personalized-scholarships-for-students/)).

### Scholarships360 (стипендии США)

- **Первый шаг.** Выбор роли: ученик, родитель, консультант; обещание «100% Free. No Spam»
  ([поиск](https://scholarships360.org/scholarships/search/)).
- **Без аккаунта.** Поиск по стипендиям в 2023 году открыли без регистрации
  ([WTOP](https://wtop.com/news/2023/12/10-sites-to-kick-off-your-scholarship-search-2)). Аккаунт нужен для личного
  подбора, а у части карточек — чтобы «подтвердить подходящесть»
  ([FAQ](https://scholarships360.org/faq/)).
- **Следующее дело.** Не нашёл.

### Niche (вузы и стипендии США)

- **Подходишь / нет.** Личный подбор стипендий — после входа
  ([Niche scholarships](https://niche.com/colleges/scholarships)).
- **Вход в воронку.** Розыгрыши «No Essay», где победителя выбирают случайно.
- **Минус.** Статусы противоречат друг другу: у одного розыгрыша показан срок 28.02.2027 и одновременно «закрыт
  навсегда» ([scholarships.com](https://www.scholarships.com/scholarships/niche-2000-no-essay-scholarship)). Пример
  того, чего Nerio избегает.

### Unibuddy (чат со студентами, встроен в сайты вузов)

- **Первый шаг.** На странице вуза выбираешь студента по программе или стране → регистрация в Unibuddy → пишешь,
  он отвечает, когда может ([Radboud](https://www.ru.nl/en/education/studying-at-radboud-university/chat-with-a-student),
  [Wageningen](https://wur.nl/en/education-programmes/chat-with-our-students.htm)).
- **Кто отвечает.** Студентов-послов отбирает вуз; чаты модерируются
  ([UCAS](https://www.ucas.com/node/412686), [Essex](https://www.essex.ac.uk/life/chat)).
- **Что это значит для Nerio.** Сервер не нужен: достаточно ссылки на официальную страницу «чат со студентами» того
  вуза, где она есть.

### Duolingo (онбординг, не поступление)

- **Порядок шагов.** Урок до регистрации; аккаунт просят после первого урока, чтобы «сохранить прогресс»
  ([UX-разбор Appcues](https://goodux.appcues.com/blog/duolingo-user-onboarding),
  [UX Collective](https://uxdesign.cc/the-duolingo-diaries-an-honest-ux-review-part-1-onboarding-ed0165d44c58)).
- **Уровень.** Выбор: начать с нуля или пройти тест уровня.
- **Цель в минутах.** 5 / 10 / 15 / 20 минут в день
  ([гид](https://duolingoguides.com/duolingo-sign-up/)).
- Это сторонние разборы; порядок шагов по версиям приложения расходится.

### EducationUSA (бесплатная сеть консультаций Госдепа США)

- **Ценность.** Пять шагов: варианты и приоритеты → бюджет и финансирование → заявки с эссе и экзаменами →
  студенческая виза → подготовка к отъезду.
- **Когда начинать.** Первый шаг — за 12–18 месяцев до начала учёбы.
- Источник — копия брошюры
  ([Scribd](https://www.scribd.com/document/479811782/your-5-steps-to-u-s-studies)); официальная страница
  ([educationusa.state.gov](https://educationusa.state.gov/your-5-steps-us-study)) не открылась.
- **Следующее дело.** Ведут в местные центры консультаций; по поиску их сотни в 170+ странах.

**Что повторяется:** профиль → список совпадений; «мало совпадений — заполни вот эти поля»; аккаунт ради личного
подбора; одно эссе на несколько заявок; выбор роли «ученик / родитель»; сначала польза, потом регистрация (Duolingo).

## 4. Что Nerio уже делает лучше аналогов

1. **Каждое поле — дословная цитата, ссылка, дата и хеш снимка.** У svenska-stipendier есть только `last_verified`,
   у scholarship-navigator — источник и дата проверки, но срок бывает «estimated» по прошлым годам. У Niche статусы
   одного розыгрыша противоречат друг другу (см. §2). У Nerio срок без даты на странице — `null`, ожидаемый срок
   подписан (`route-view.js`: «дата ожидаемая»).
2. **Ответ по правилам с причиной — без аккаунта и без данных на сервере.** Going Merry, Bold.org, Scholarships360 и
   Niche дают личный подбор только после регистрации, Unibuddy — чат только после регистрации (ссылки в §2). В Nerio
   анкета хранится на устройстве, а вердикт объясняет причину.
3. **Русский язык и программы для Центральной Азии в одном месте.** Найденные открытые аналоги — по одной стране или
   региону: Швеция, Таиланд, Китай, Erasmus Mundus для Египта и Африки; написаны на английском, китайском, тайском.
   Русскоязычного инструмента «условия + дела до срока» поиск не нашёл; из русскоязычных есть только чек-листы виз в
   Корею. При этом Nerio не выставляет «балл совпадения» вроде 0–100 у scholarship-navigator.

## 5. Решить Муроду

- **Лицензия Nerio.** Файла `LICENSE` нет — сейчас код закрыт по умолчанию. Брать MIT/ISC/Apache-код это не мешает
  (нужно сохранить их уведомления). Открыть каталог как данные (идея zakon-quest и svenska-stipendier) без решения
  о лицензии нельзя.
- **Канал «нашёл ошибку»** для идеи 8: почта, Telegram или форма.

  домены из начала отчёта (меню окружения в заголовке сессии → Edit → Network access, порядок шагов:
