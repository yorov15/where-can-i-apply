# Материалы заявки: схема `data/materials/<id>.json`

25.11.2026, черновик Claude. Нужна для шага «Что просят мои цели» в `docs/PORTFOLIO-SCENARIO.md`. Валидатор (`tools/materials.py`) и тесты пишет Claude до старта DS-1. Пока валидатора нет, файлы не вносить.

## Файл программы

```json
{
  "id": "kaist",
  "checkedAt": "2026-11-26",
  "items": [
    {
      "type": "essay",
      "need": "required",
      "count": 2,
      "limit": {"unit": "chars", "max": 1500},
      "prompt": "Дословный вопрос из формы, если он есть",
      "who": null,
      "language": "en",
      "via": "form",
      "ru": "Два эссе на английском до 1500 знаков каждое: о себе и о плане учёбы.",
      "evidence": "Дословная цитата со страницы",
      "source": {
        "url": "https://…",
        "lastVerified": "2026-11-26",
        "contentHash": "sha256:<64 знака>"
      }
    }
  ],
  "notStated": ["video", "cv"],
  "note": null
}
```

## Поля пункта

| Поле | Значения | Правило |
|---|---|---|
| `type` | `essay`, `recommendation`, `activities`, `cv`, `awards`, `portfolio`, `studyPlan`, `video`, `interview`, `certificates`, `other` | один пункт — один материал; два разных эссе — два пункта |
| `need` | `required`, `optional`, `some` | `some` — нужно только части поступающих (например, на одну специальность); кому именно — в `ru` |
| `count` | число или `null` | только если число названо в цитате |
| `limit` | `{unit: words\|chars\|pages\|minutes\|items, max}` или `null` | только из цитаты; «около 500 слов» → `max: 500`, слово «около» — в `ru` |
| `prompt` | строка или `null` | вопрос эссе дословно, на языке источника |
| `who` | `teacher`, `counselor`, `principal`, `any`, `null` | только для `recommendation` |
| `language` | код языка или `null` | язык, на котором подавать материал |
| `via` | `form`, `upload`, `platform`, `mail`, `email`, `null` | как сдаётся материал |
| `ru` | строка до 300 знаков | для ученика, по-русски, без канцелярита; ничего сверх цитаты |
| `evidence` | строка | дословная подстрока снимка из `raw/`; проверяется как в `tools/validate.py` |
| `source` | как в `applyChannel` | снимок того же дня или свежее |

## Чего нет и что «не указано»

- `notStated` — материалы, которые искали на официальных страницах программы и не нашли упоминания. Это не «не нужно», а «программа не пишет». Интерфейс так и скажет.
- Отсутствие типа и в `items`, и в `notStated` значит «не проверяли».
- Не нашли официальную страницу с требованиями — файл не создаётся, причина пишется в отчёт.
- Справки и документы (паспорт, аттестат, переводы, медицинская) сюда не входят: они уже в `data/prep/docs/`. Сюда только то, что ученик пишет, собирает или просит у людей.

## Чего не делать

- Не переносить требования из одной программы вуза в другую без цитаты на каждую.
- Не путать бакалавриат с магистратурой и подготовительным годом.
- Не заполнять `count` или `limit` «по аналогии».
- Не переводить `prompt` и `evidence`.
