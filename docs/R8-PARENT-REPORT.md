# Недельный отчёт родителю

Реализовано 27.10.2026, код `2b64914`.

В маршруте доступны предпросмотр, копирование текста и отдельная печать отчёта с сохранением в PDF.
Текст до 1200 знаков: цели, план часов, отмеченные дела за текущую неделю пн–вс по сегодняшний день,
следующие дела, ближайший открытый срок подачи и плата за подачу.

Галочки без даты после миграции, будущие даты и снятые отметки не считаются выполнением за неделю.
Дело в общем маршруте и его недельная копия считаются один раз. Часы обозначают план, не измеренное
время работы. Снятие галочки в маршруте убирает её дату из недельного списка.

Деньги берутся через существующий `planCost` из размеченных `fee`: валюты отдельно, условное снятие
платы при запросе финансовой помощи отдельно, неизвестные суммы явно обозначены. Даты оплаты в
данных не подтверждены; дата подачи не выдаётся за срок платежа.

Проверено: 539 JS-тестов, 472 Python-теста, сборка, Chromium на 375/1280 px в обеих темах. Из четырёх
PDF извлечён текст через независимый `pypdf`; все знаки кроме пробелов совпадают с предпросмотром и
скопированным текстом. Анкета и остальной маршрут в PDF отчёта не входят. Проверены снятие отметки,
перезагрузка, сброс и возврат из режима печати. Все четыре приёмочные проверки R8 пройдены.
