5. **Хранение.** Поле `recommenders` в состоянии маршрута v2 (`js/route-state.js`), входит в экспорт и импорт.

   Схема не менялась, миграция не нужна.

## Правило детектора

- Читаются пункты `textConditions` с `kind: "documents"`. Признак письма — в русском тексте пункта:
  `рекомендательн`, `рекомендаци`, `референс`.
- Перед проверкой из текста вырезается то, что письмом о тебе не является: «саморекомендация» (ECNU),
  «по рекомендации …» (MEXT, посольство, вуз, директор), «настоятельная рекомендация» (совет сдать экзамен),
  «наравне с … рекомендациями» (пункт про эссе у Tufts, личное заявление у LSE).
- Запасной путь: если в документах письма нет, берутся пункты `must`/`steps`, но только когда о письме
  говорит и сама цитата (recommend, referee, reference, teacher evaluation, 推荐, 推薦). Так нашлась Nottingham
  Ningbo; KFUPM отброшен — его цитата про собеседование.
- Насколько нужно, по тексту пункта: «не требуются / не используются / не рассматриваются / просят не
  присылать» → не нужны; «по желанию / необязательно / на выбор / при наличии / если применимо / добровольно …»
  → по желанию (кроме «вторую можно добавить по желанию» — тогда первое письмо обязательно, NYU Shanghai);
  «только при / для стипендии / если потребуется / может потребовать / некоторые направления / для отдельных
  программ / для пути без …» → в отдельных случаях; иначе — нужны. У программы берётся самый строгий пункт.
- Число — только из цитаты: «two recommendation letters», «one counselor recommendation and two teacher
  recommendations» (складываются части), «Teacher recommendations: Two are required», «at least two»,
  «up to two», «(2)», «推荐信2份». Цифры без скобок не берутся: в списках это номер пункта («12 Letter of
  Recommendation»). Общее число программы — только если каждый главный пункт назвал своё; иначе «в цитате
  числа нет, смотри условие ниже».

1. `python -m http.server 8765`, открыть `http://localhost:8765/`.
2. Добавить в «Мой путь» программы с близким сроком, например «Стипендия правительства Китая (CSC)» (19.12.2026)
   и «Гарвардский колледж» (01.01.2027), плюс KTH (письма не нужны) и NYU Shanghai.
3. «Мой путь» → «Подготовка» → блок «Рекомендации» внизу правой колонки (на телефоне — после эссе).
   Проверить строки «Нужно 2 письма», «Попросить до …», цитаты в «Что пишет программа».
4. «Добавить рекомендателя»: имя, предмет, отметить CSC и Гарвард. Открыть карточку, нажать три кнопки
   копирования, вставить куда-нибудь. Поменять статус — дата просьбы появится сама.
5. «Сегодня»: дело с именем человека (CSC: попросить до 7 ноября). «Попросил» — дело исчезает.
6. Поменять «За сколько недель» на 2 — дело на «Сегодня» пропадает (до 5 декабря больше недели).
7. «Файл и данные» → «Скачать маршрут» → «Загрузить маршрут»: рекомендатели на месте.

## Чего не сделано и почему

- **Нет дела «Реши, кого попросить», пока рекомендателей нет.** Задача просила дело «Попроси у …» с именем;
  без имени это было бы второе напоминание к каждой цели. Блок в «Моём пути» показывает «Пока никого».
- **Нет напоминания в календаре `.ics`.** Не просили; можно добавить датой «попросить до».
- **Только русский текст памятки.** Письмо есть на двух языках, памятка — на русском, как в задаче.
- **Нет статуса «Отказался».** Если учитель отказал, программу снимают с человека в «Изменить» или удаляют запись.
- **Строки в `AGENTS.md` нет.** По образцу прошлых веток её пишут при слиянии в `main`, чтобы не ловить
  конфликты с параллельными сессиями.
- Ученики, Safari/iOS и реальная вставка в почту не проверены. Буфер обмена проверен в Chromium.
