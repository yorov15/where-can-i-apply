## Жёсткие правила проекта

- Ничего не писать по памяти: у каждого поля цитата, ссылка, дата, хеш страницы. Нет источника — пометка
  «не подтверждено», а не догадка.
- Тесты: `node --test` и `python -m unittest discover -s tools/tests -t .`. Зелёные перед слиянием.
- Стадить только явные пути, никогда `git add -A` / `commit -a`.
- Секретов в репозиторий не класть.
