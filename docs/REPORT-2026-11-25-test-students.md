## Как собраны старые файлы

Для каждого коммита папка `js/` извлекалась через `git archive <commit> js`, затем
вымышленное состояние пропускалось через `exportState()` этого коммита. Каждый файл
проверен `importState()` своего коммита и текущим `importState()`; потерь записей нет.
Файл `06-current.json` собран текущим `exportState()` на коммите `b3d5974`. Содержимое
состояния задано вручную и вымышлено; из репозитория взяты только функции экспорта и
тексты учебных уроков.

«Материалы цели» в `05-with-goal-materials.json` — это `applicationNotes` (истории и
сведения о школе) и `applications.materials` (версии материалов заявки по цели).
