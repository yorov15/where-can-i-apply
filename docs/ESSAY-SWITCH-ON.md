# Как включить «Проверь мой черновик» (М3)

27.11.2026.

## Правило

**Не включать людям, пока экзамен не прошёл.** Экзамен прошёл — это строка `EXAM-OK`: выдумок 0 и годных отзывов не меньше 9 из 10. Перед включением прочитать ответы в файле экзамена глазами: отзыв не пишет текст за автора, не повторяет имя и контакты, его можно понять.

## Как устроено сейчас

- Модель: при ключе Go (`OPENCODE_API_KEY`) — только `go/deepseek-v4.1-flash`. В таблице приватности [Go](https://opencode.ai/docs/go/) у неё 0 дней хранения. `EXPLAIN_MODELS` на эссе не влияет. Без ключа Go — `openrouter/free` с запретом хранения и сбора данных. Без ключей режим выключен.
- Режим `essay` принимает черновики, как только есть модель. Поэтому экзамен можно гонять на живой функции сразу после выкладки.
- Кнопку людям показывает `essay-status`. Он отвечает `available:true`, только когда есть ключ Go и включено одно из двух:
  - константа `ESSAY_PUBLIC = true` в `api/_essay-core.js` — основной путь, в Vercel ничего менять не надо;
  - переменная `ESSAY_REVIEW_ENABLED=1` в Vercel — запасной путь.
- С 27.11.2026 `ESSAY_PUBLIC = true`: экзамен на живой функции 10 из 10, выдумок 0; `privacy.html` переписан под Go.

## Порядок

1. Выложить функцию (ветка с М3 в `main`, выкладка как обычно).
2. Запустить экзамен:

   ```
   node tools/essay-exam.mjs
   ```

   Флаги: `--url` (по умолчанию `https://nerio-app.vercel.app/api/explain`), `--out` (файл с ответами, по умолчанию `essay-exam-answers.json`), `--min 9`. Набор — 10 черновиков в `tests/fixtures/essay-exam/cases.json` (AUCA, KAIST, NCKU; русский и английский, слабые и приличные, атака внутри текста, контакты, перебор объёма). В ответах есть `trace`: какая модель, сколько миллисекунд и почему отбракован ответ (`reject`).
3. Нет `EXAM-OK` — не включать. Смотреть `reject` в файле: правится подсказка `ESSAY_SYSTEM` или проверка `inspectEssayFeedback` в `api/_essay-core.js`, тесты, выкладка, экзамен заново.
4. Есть `EXAM-OK` и ответы читаются нормально — поставить `ESSAY_PUBLIC = true`, поправить тест `ESSAY_PUBLIC` в `tests/essay.test.js` и `tests/explain-essay-attacks.test.js`, выложить.
5. Сменили модель — экзамен заново, до включения.

## Что ещё до включения

- `privacy.html` пишет, что эссе уходит в OpenRouter. Переписать под Go до того, как поставить `ESSAY_PUBLIC = true`.
- Лимиты: 3 проверки в день на браузер, 12 за 10 минут с одного адреса, 150 в день на экземпляр функции (`ESSAY_DAILY_LIMIT`).
