# Кандидаты в новые программы: домены на одобрение (2026-09-24)

Правило проекта: домен источника утверждает человек, поэтому ассистент сам ничего в
`tools/sources.toml` не добавлял. Ниже кандидаты, которых нет среди 56. Домены проверены
только на то, что открываются (HTTP 200); страницы с требованиями ещё не выбирались.
Ответ достаточно дать списком id: «да» / «нет». После «да» ассистент выбирает страницы внутри
домена, прогоняет `fetch → extract → review → build` и сливает.
