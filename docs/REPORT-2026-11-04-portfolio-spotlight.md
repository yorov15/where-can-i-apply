# Подборка под цель — 04.11.2026

Ветка `claude/portfolio-spotlight` от `main` (`9a2e8cb`). В `main` не влито, на прод не выложено.

## Что сделано

- **Выбор.** У каждой цели в «Моём пути» (разделы «Подготовка» и «Заявки») есть кнопка «Собрать подборку». В разделе «Работы» есть свёрнутый блок «Подборка под цель» со ссылкой на каждую цель. Адрес выбора: `#route/spotlight/<id>`.
  - Человек отмечает до 5 записей опыта или работ. Когда отмечено пять, остальные галочки выключаются.
  - Порядок меняется кнопками «↑ Выше» / «↓ Ниже». Фокус остаётся на перемещённой записи.
  - У каждой записи одна строка «Что сделал и что вышло», до 150 знаков, со счётчиком «N из 150 знаков». Рядом подпись: «это формат Nerio, не требование программы».
  - Подсказка к пустой строке берётся только из того, что записано в самой записи. Сначала «Что получилось». Если поле пустое — последний результат задания этой работы. Если нет и его — навыки записи. Длинный текст обрезается по слову до 150 знаков. Подсказку можно вставить кнопкой «Вставить». Если записать нечего, видна строка «В записи пока нет итога и навыков — напиши своими словами».
  - Есть необязательное поле «Имя на странице». В анкете поля имени нет, поэтому имя вводится здесь, иначе на странице его не будет.
  - Всё сохраняется сразу, при каждом изменении. Отдельной кнопки «Сохранить» нет.
- **Строки программы.** Если в условиях программы (`kind: documents`) есть текст о внеучебном опыте, он показан блоком «Что пишет программа о внеучебном опыте» со ссылкой «Источник». Такой текст есть у 11 программ, например «до трёх» у Waseda SILS и «три текста до 100 слов» у Tokyo College of Design. Отдельного поля «лимит списка активностей» в данных нет. Новых фактов в `data/` не добавлено.
- **Страница** `#route/spotlight/<id>/page`. На ней:
  - заголовок, программа (короткое имя, до « — »), имя, если оно введено;
  - 1–5 записей: вид, сроки, строка, роль, итог, навыки, ссылки (ссылка записи и ссылка последнего результата задания).
  - Кнопка «Печать / PDF»: `window.print()`, на бумагу уходит только лист подборки. Ctrl+P на этой странице печатает так же.
  - Кнопка «Скопировать текстом»: буфер обмена. Если браузер не дал доступ к буферу, появляется поле с текстом, выделенным для ручного копирования.
  - Данные берутся из локального состояния, сеть не нужна.
- **Подсказки без оценок.** Если в подборке меньше 3 записей — «Добавь ещё работу в портфолио» со ссылкой на `#route/new`. Если у записи нет итога — «Допиши итог: что получилось · <название>», ссылка открывает эту запись. Слов «сильная/слабая» нет.
- **Функция для других экранов.** `spotlightText(state, goalId, {programName, name})` в `js/spotlight.js` — чистая функция без DOM. Возвращает текст подборки или пустую строку. Без `programName` вместо названия программы стоит id. Пример вывода — тест «spotlightText отдаёт текст подборки» в `tests/spotlight.test.js`.

## Хранение

Новое необязательное поле состояния v2 — `spotlight`:

```json
{ "version": 1, "name": "…", "goals": { "<goalId>": { "items": [{ "experienceId": "…", "line": "…" }], "updatedOn": "YYYY-MM-DD" } } }
```

- Пустую подборку не храним, поэтому старые файлы и экспорт без неё не меняются ни на байт (есть тест).
- Повреждённая структура отклоняет импорт целиком, как у портфолио.
- Ссылки на удалённые записи опыта молча выпадают, файл остаётся рабочим.
- Миграция не нужна. Подборка входит в общий экспорт и импорт.

## Как проверить руками

1. В «Моём пути» → «Работы» должно быть 2–3 записи и хотя бы одна цель.
2. «Заявки» → раскрыть цель → «Собрать подборку». Отметить записи, поменять порядок стрелками, вставить подсказку, перезагрузить страницу — всё должно остаться на месте.
3. «Открыть подборку» → «Печать / PDF». В окне печати только подборка на A4.
4. «Скопировать текстом» → вставить в заметку.
5. Выключить сеть (DevTools → Offline), перезагрузить, открыть `#route/spotlight/<id>/page`. После первого визита страница открывается из кэша сервис-воркера.

## Не сделано и почему

- Своего поля «лимит списка активностей» с цитатой в данных нет. Показан подписанный текст условия и ссылка на источник. Английская цитата в клиент не попадает: сборка вырезает `evidence`. Чтобы показывать цитату, нужна правка сборки и данных — это отдельная задача.
- Поля имени в анкете нет. Имя вводится в самой подборке, а не берётся из анкеты.
- Офлайн проверен только логически: страница строится из локального состояния, файлы отдаёт сервис-воркер. Режим «Offline» руками не включали.
- Safari/iOS, настоящий принтер и ученики не проверены.
- Счётчик считает знаки по символам. `maxLength` у поля считает по UTF-16, поэтому с эмодзи поле упрётся в предел чуть раньше 150 видимых знаков. Превысить предел нельзя.
