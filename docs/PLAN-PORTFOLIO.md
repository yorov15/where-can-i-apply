# Портфолио: первая партия

Мурод одобрил реализацию 28.10.2026 после исследования SelfStart, Crimson и аналогов.
Работа от `redesign-v2`, отдельно на `codex/nerio-portfolio`; выпуск в main и на прод ждёт D0.

## Объём

1. «Мой опыт и работы» в «Моём пути», в том числе без выбранной цели: добавить, изменить, удалить запись.
2. Контекст/период, собственная роль, действия, результат, вывод и необязательная ссылка. Связи с выбранными целями и собственное объяснение полезности.
3. Результат существующего недельного задания: текст, ссылка, вывод, необязательная связь с опытом. Галочка выполнения и запись результата независимы.
4. Дополнительный раздел состояния маршрута с собственной версией, сохранение на устройстве, общий экспорт/импорт. Старые файлы маршрута продолжают работать. Перед импортом явно сообщается о замене текущих данных.

Данные программ, критерии отбора, расчёт недельной нагрузки, AI-эссе и навигация этой партией не меняются. Связь опыта с целью — заметка участника, не официальное требование или оценка комиссии. Бинарных вложений нет: текст и ссылки.

## Проверка

- Нормализация и сохранение: старые файлы, восстановление полного нового набора, безопасные ссылки/идентификаторы, отбраковка неизвестной версии без замены текущих данных, лимит размера.
- Связи: удаление цели не удаляет опыт; удаление опыта сохраняет тексты результатов; пересборка недели не теряет результаты.
- Браузер: добавление, редактирование, привязка, результат задания, перезагрузка, экспорт и восстановление; 375/1280 px, обе темы, клавиатура.
- Оба набора тестов, сборка, лимит CSS и preload новых модулей.

Основные материалы исследования находятся в папке чата `outputs/`: `NERIO-RESEARCH.md`, `PREPARATION-PLAYBOOK.md`, `NERIO-PORTFOLIO-SPEC.md`. Этот план фиксирует только согласованную первую партию.
