## Что работает сейчас

- В маршруте появились требования к эссе 11 программ: 17 отдельных полей или заданий. У 10 полей
  разобраны точные формулировки; для остальных есть ссылка на форму программы и явная пометка,
  что точный вопрос пока не разобран. Неизвестные лимиты остаются неизвестными.
- Есть чек-лист требований, вопросы для поиска своей темы, поле черновика и счётчик слов, знаков
  и байтов. KAIST размечен по шести полям приложения, с отдельными пределами знаков и байтов.
- Черновик, галочки чек-листа и отзыв существуют только в памяти страницы. Перезагрузка очищает
  их; файл маршрута, браузерное хранилище и аналитика их не получают.
- Проверка доступности отправляет только `{mode: "essay-status"}`. При выключенном переключателе
  API возвращает `available: false`, а кнопка отправки черновика отсутствует на экране.
- Правила ICU, Nagoya G30, Hokkaido ISP и Tohoku учитываются отдельно: их тексты не отправляются
  в ИИ-проверку. Для Hokkaido источник запрещает профессиональную вычитку; продукт отключает
  ИИ-проверку, не выдавая эту формулировку за прямой запрет ИИ.

Факты лежат в `data/prep/<id>.json → essays/essayPolicy`. Небольшие выдержки сохранены в
`raw/essays/2026-10-27/`. Сборка проверяет цитату, хеш выдержки, URL/хеш одобренной страницы,
дату, числовые пределы и отсутствие выдуманного вопроса. Крупные тексты не включены в индекс:
данные выбранных целей подгружаются отдельно и допускают повтор после ошибки.

## Что подготовлено для будущего включения

Только после нового поручения Мурода нужны пригодный ключ OpenRouter и `ESSAY_REVIEW_ENABLED=1`
в Vercel с новой выкладкой. Если существующий ключ принадлежит OpenCode Go, сохранить его в
`OPENCODE_API_KEY`, не затирать при настройке OpenRouter. В этой задаче переменные не менялись.

Будущий режим `api/explain` принимает один черновик и ID задания. Вопрос и ограничения берёт
из данных сервера. Возвращает замечания по ответу на вопрос, ходу мысли и вопросы автору.
Доступны только `openrouter/free`, нулевая максимальная цена, `data_collection: deny`, `zdr: true`.
Платного запасного пути нет. Эти параметры сверены с документацией
[бесплатного роутера](https://openrouter.ai/docs/guides/routing/routers/free-router) и
[маршрутизации провайдеров](https://openrouter.ai/docs/guides/routing/provider-selection).

Лимит — три попытки на местный календарный день браузера, включая ошибки. Web Locks защищает
одновременные вкладки; резерв записывается до запроса. При недоступном хранилище или блокировках
отправка закрыта. Дополнительный серверный счётчик — три обращения на случайный ID за день UTC
в памяти одного экземпляра. Это не учёт личности: очистка хранилища, другой браузер и несколько
экземпляров сервера ограничивают точность. Согласованный предел не выдаётся за защиту от обхода.

API не сохраняет черновик или отзыв в кэше и не передаёт модели ID устройства. Структурированный
ответ с лишним полем переписанного эссе, контактами, HTML или процентом поступления отклоняется.
Настоящий отзыв от модели на проде не получен: до решения отложить ИИ функция вернула `503/off`.
После этого решения живые черновики не отправлялись.
