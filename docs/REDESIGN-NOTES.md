## 2. Что такое Bedrock по существу

Стиль — мягкий необрутализм. Держится он на пяти приёмах:

1. **Чернильная обводка 2px** у каждой карточки, кнопки и плитки.
2. **Жёсткая тень без размытия**, сдвиг 3px (мелкое) и 5px (крупное). При нажатии кнопка «вдавливается»: тень пропадает, кнопка сдвигается на её место.
3. **Пастельные заливки** для смысловых плиток (голубой, персиковый, сиреневый, мятный) с чёрным текстом. Контраст везде 14:1 и выше.
4. **Жёлтый маркер** за одним ключевым словом в заголовке и жёлтая шапка у активного блока.
5. **Один вопрос на экран** в онбординге: крупный вопрос, одна главная кнопка, тихая ссылка «пропустить».

Плюс то, как устроен банк задач: счётчик «4/125 решено», дальше темы, внутри каждой темы сетка пронумерованных плиток. Состояние плитки видно по цвету, без текста. Это ровно то, что нужно шагам портфолио.

Чего у Bedrock нет: тёмной темы, кириллицы, длинных форм. Это придётся делать самим.

## 4. Токены под Nerio

Почему не копировать цвета Bedrock один в один: их коралл `#EE4E29` на светлом фоне даёт 3,4:1, а белый текст на нём 3,7:1. Для мелкого текста это ниже нормы.

### Светлая тема

|---|---|---|
| `--bg` | `#F7F6F2` | фон |
| `--surface` | `#FFFFFF` | карточки |
| `--ink` | `#141414` | текст, обводка, тень |
| `--accent` | `#C93D1C` | тот же коралл, темнее: 4,7:1 на фоне, белый на нём 5,0:1 |
| `--mark` | `#FFE135` | маркер и активная строка, чёрный на нём 14:1 |
| `--tile-sky / -peach / -lilac / -mint` | `#C9E8FF / #FFE0CB / #EDE9FF / #C8F0D0` | плитки шагов и типов материалов |
| `--bw` | `2px` | обводка |
| `--sh-1 / --sh-2` | `3px 3px 0 var(--ink)` / `5px 5px 0 var(--ink)` | тени |
| `--r-tile / --r-card` | `8px / 16px` | кнопки и метки — полный радиус |

**Решено 25.11.2026:** Мурод выбрал коралл. Синий снят везде, включая `theme-color` страниц и манифест. Белый в CSS — `#fefefe`, потому что тест запрещает чистые `#fff` и `#000`.
