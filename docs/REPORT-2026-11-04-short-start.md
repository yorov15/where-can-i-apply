# Предварительное число в анкете — 04.11.2026

Ветка `claude/short-start`. В `main` не влито, не выложено.

## Что сделано

1. **Строка под кнопками мастера.** Как только в анкете есть хоть один ответ (обычно гражданство в разделе «Кто ты»), под кнопками появляется строка «Пока ничего не мешает: 274 программы. Число уточнится, когда ответишь дальше.» На последнем разделе хвоста нет: ответов, меняющих число, там больше нет. Если по ответам не осталось ничего — «По этим ответам открытых программ не осталось. Проверь, всё ли выбрано верно.» Слов «подходишь», «шанс» нет (проверяется тестом).
   - Считается: программы с незакрытым приёмом (`deadlineState !== 'closed'`, неизвестный срок считается открытым, как в `readySummary`), у которых `evaluate` не даёт `no`, то есть нет ни одной причины `fail`.
   - Пустые поля правила и так считают `unknown`, а не `fail` (`js/rules.js`: `*.no-value`, у языка без сертификата — `language.no-certificate`, у SAT/ACT — `unknown`). Поэтому частичный профиль подаётся в `evaluate` как есть, без своей логики «что уже отвечено».
   - Пустой анкете строка не показывается: число там равно всему каталогу.
   - Строка видна только пока идёт мастер (первое заполнение). В режиме правки всей анкеты её нет — там ответ и так рядом.
2. **«Посмотреть сейчас».** Тихая ссылка-кнопка под строкой. Видна, когда заполнено обязательное (`profileReady`: гражданство, страна школы, годы школы, год выпуска), то есть с раздела «Выпуск и возраст» после ввода года и дальше; на последнем разделе скрыта — там та же главная кнопка. Нажатие идёт тем же путём, что «Показать, куда можно подать» (`finishButton.click()`): проверка полей с ошибкой, конец мастера, экран «Куда можно» с личным ответом.
   - На разделе «Кто ты» кнопки нет. Причина: без года выпуска `profileReady` ложно, и `renderResults` показывает каталог без проверки, а не результат; сводка, «Мой путь» и «Программа» тоже завязаны на `profileReady`. Ослаблять это условие — значит менять поведение всех экранов, это не «без ломки». Строка из п.1 на этом разделе есть.
   - После «Посмотреть сейчас» мастер закончен, как после главной кнопки: оставшиеся разделы человек правит через «изменить» (вся анкета разом). Это прежнее поведение мастера.
3. **Пояснение в «Что тебе важнее» (аудит, п. 9).** Длинный абзац заменён одной фразой: «Кнопки «Любое направление» нет: программа на весь вуз уже входит в число у каждого направления.» Смысл двух цифр у страны — рядом с ними: подпись под заголовком «Страны» («Второе число — сколько из этих программ в конкретном вузе.») и `title` на каждой кнопке страны («17 программ, из них в конкретном вузе — 17»), `js/priority.js`.
4. **Скорость.** Пересчёт по `input`/`change` с паузой 200 мс (`clearTimeout` + `setTimeout`), сразу — по «Далее»/«Назад», по загрузке списка программ и при перезапуске мастера. Один подсчёт на 323 программах — ~1 мс в Node на сервере (100 прогонов).
5. **Вёрстка.** Попутно две старые поломки на 280 px в этой же анкете (были и в `main`, проверено на `git stash`):
   - кнопка «Математика и естественные науки» шире экрана → горизонтальная прокрутка страницы (313 px при 280): `#profile .chip{max-width:100%}`;
   - кнопки мастера рвали слова посередине («Дале/е», «Пока/зать»): на экранах до 20rem боковой отступ кнопок 12 px вместо 24.

## Как проверить руками

1. `python -m http.server 8765`, открыть `http://localhost:8765/#profile` в чистом профиле браузера (или «Очистить данные на этом устройстве»).
2. Выбрать гражданство — через ~0,2 с под «Далее» появится строка с числом. Поменять гражданство — число меняется.
3. Заполнить раздел, «Далее», ввести год выпуска — появится «Посмотреть сейчас». Нажать — откроется «Куда можно» с личным ответом.
4. Пройти до «Что тебе важнее»: короткое пояснение, подпись у «Страны», подсказка при наведении на страну, строка без «Число уточнится».
5. Узкий экран 280 px: нет горизонтальной прокрутки, слова в кнопках не рвутся.
