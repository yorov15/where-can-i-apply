# Инструмент проверки правомочности — дизайн v1

Дата: 2026-09-03
Статус: на утверждении

## 1. Что это

Статический веб-сайт. Пользователь заполняет короткую анкету о себе; сайт
показывает, в какие программы обучения за рубежом он может подать документы, в
какие не может и по какой именно причине.

Аудитория — школьники Таджикистана и Центральной Азии.

Правомочность проверяется **на уровне программы, а не университета**. Одна
запись вроде Türkiye Bursları покрывает шесть десятков вузов сразу, потому что
человек подаётся в программу, а вузы выбирает внутри заявки. Инструмент доводит
до двери; меню за дверью — на сайте программы.

### Чем инструмент не является

Не рейтингом, не советчиком по выбору вуза, не оценщиком шансов на поступление.
Он отвечает на один вопрос: пускают ли тебя вообще подавать документы.

## 2. Стек

- Сайт: HTML, CSS, JavaScript без фреймворков и без сборки.
- Данные: JSON, файл на программу.
- Сборщик данных: Python 3.12.
- Тесты: node --test, без зависимостей.
- Хостинг: GitHub Pages.
- Бэкенда нет физически.

## 3. Схема профиля

Семь полей. Хранится в localStorage, устройство не покидает.

```json
{
  "citizenship": "TJ",
  "schoolCountry": "TJ",
  "schoolYears": 11,
  "graduationYear": 2027,
  "birthDate": "2008-08-09",
  "gpa": { "value": 4.8, "scale": "TJ_5" },
  "languageTests": [
    { "test": "IELTS", "score": 7.0 },
    { "test": "TOEFL_IBT", "score": null }
  ]
}
```

Обоснование решений:

- citizenship и schoolCountry разделены: российская квота смотрит на гражданство,
  MEXT — на систему образования, в которой человек учился. У гражданина
  Таджикистана, окончившего школу в России, эти условия расходятся.
- birthDate, а не возраст: возраст в правилах считается на дату дедлайна или на
  1 апреля года заезда, а не на сегодня. Из числа «17» правильный ответ не
  восстановить.
- gpa со шкалой: 4.8 без указания шкалы не значит ничего. Конвертация живёт в
  одном месте движка.
- languageTests массив: у человека может быть несколько сертификатов, а программе
  достаточно одного. score null означает «планирую сдавать» и отличается от
  отсутствия записи.

Сознательно не включены: пол, финансовая нужда, SAT, профиль предметов. Каждое
поле — это ещё один вопрос в анкете и ещё одно поле, которое надо честно
заполнить в тридцати программах. Ждут расширения на живом инструменте.

Что такое gpa до выпуска: текущие оценки за четверть. Это то единственное число,
которое школьник в Таджикистане реально может назвать до получения аттестата.

Отсюда следствие, которое надо держать в голове: четвертной балл гуляет от
четверти к четверти, а программы почти всегда спрашивают средний по аттестату
или по всем годам. То есть входное число и число в требованиях — не одна и та же
величина. Поэтому сравнение по gpa в движке остаётся приблизительным по
построению, а не только из-за разницы шкал, и полоса неопределённости в 5
процентных пунктов работает на оба источника погрешности сразу. В форме поле
подписывается прямо: «средний балл за последнюю четверть», плюс пояснение, что
итоговый балл аттестата может отличаться и решает он.

## 4. Схема программы

Файл `data/programs/<id>.json`.

```json
{
  "id": "turkiye-burslari",
  "status": "published",
  "name": { "ru": "Türkiye Bursları", "orig": "Türkiye Scholarships" },
  "hostCountry": "TR",
  "level": "bachelor",

  "coverage": {
    "tuition": true,
    "living": true,
    "travel": true,
    "note": { "ru": "Плюс год турецкого языка до начала учёбы" }
  },

  "eligibility": {
    "citizenship": { "allow": "*", "deny": ["TR"], "evidence": "..." },
    "schoolCountry": null,
    "schoolYears": null,
    "graduationYear": { "min": 2025, "max": null, "evidence": "..." },
    "age": { "max": 21, "asOf": "deadline", "evidence": "..." },
    "gpa": { "min": 70, "scale": "PERCENT", "evidence": "..." },
    "language": null
  },

  "textConditions": [
    { "ru": "Нельзя подавать, если уже учишься в турецком вузе на той же ступени",
      "evidence": "..." }
  ],

  "deadline": {
    "opens": "2027-01-10",
    "closes": "2027-02-20",
    "recurring": "annual",
    "confidence": "expected"
  },

  "applyUrl": "https://turkiyeburslari.gov.tr/",

  "coversInstitutions": {
    "kind": "chosen-in-application",
    "approxCount": 60,
    "note": { "ru": "Вузы выбираются внутри одной заявки, до 12 вариантов" }
  },

  "source": {
    "url": "https://turkiyeburslari.gov.tr/...",
    "lastVerified": "2026-09-03",
    "contentHash": "sha256:...",
    "humanChecked": true
  }
}
```

Обоснование решений:

- eligibility повторяет профиль ключ в ключ. Семь полей — семь правил — семь
  функций движка. Ошибку в правиле возраста нельзя занести в правило языка.
  Восьмое поле в будущем добавляется, не трогая существующие.
- evidence лежит внутри каждого правила, а не отдельным блоком: иначе при
  обновлении источника значение и цитата разъедутся.
- У правила три состояния, а не два. **Объект с цитатой** — требование есть,
  цитата проверяется поиском по тексту источника. **null** — «в источнике
  этого нет»: не смотрели или не нашли, даёт жёлтый вердикт. **noLimit** —
  «человек прочитал страницу, требования там нет».

  Третье состояние добавлено 3 сентября 2026, после первой настоящей записи.
  Изначально предполагалось, что отсутствие ограничения записывается объектом
  с пустыми значениями и цитатой, которая это подтверждает. На живой странице
  оказалось, что такой цитаты обычно не существует: на сайтах программ нет
  абзаца «возрастных ограничений не установлено». Отсутствие требования
  подтверждает не фраза, а человек, прочитавший страницу. Без этого состояния
  почти каждая запись выходила жёлтой, и светофор переставал различать.

  Правило с `noLimit: true` проходит без цитаты, но требует подпись:
  `checkedBy: "human"`, дату `checkedAt` и пояснение `note`. Значений в нём
  быть не может — ни `min`, ни `max`, ни `allow`, ни `deny`, ни `anyOf`, ни
  `scale`, ни `asOf`. Ручаться можно за отсутствие ограничения и никогда за
  число: как только появляется значение, цитата снова обязательна. Подпись
  ставит `review.py` при подтверждении, у модели такой возможности нет.
- citizenship.allow со звёздочкой плюс deny: списки на полтораста стран
  устаревают ежегодно; где список короткий, он пишется списком.
- age.asOf: у MEXT возраст считается на 1 апреля, у Türkiye — на дату подачи.
  Без поля инструмент ошибается на тех, кто в пограничном возрасте.
- deadline.confidence: даты следующего цикла обычно неизвестны и берутся по
  прошлому году. expected рисуется иначе, чем confirmed.

Сознательно не хранятся: рейтинг вуза, стоимость жизни, оценка шансов. Всё, что
нельзя подтвердить цитатой из первоисточника, в схему не попадает. Личный фильтр
автора «топ-150» в продукт не протекает.

## 5. Движок вердикта

Семь чистых функций, по одной на поле:

```
checkCitizenship(profile, rule) -> { status, message }
checkSchoolCountry(...)
checkSchoolYears(...)
checkGraduationYear(...)
checkAge(...)
checkGpa(...)
checkLanguage(...)
```

status — pass, fail или unknown. Функции не читают DOM, не ходят в сеть, ничего
не пишут.

Сборка:

```
есть fail          -> «не подходишь»     (красный)
иначе есть unknown -> «надо проверить»   (жёлтый)
иначе              -> «подходишь»        (зелёный)
```

Показываются сначала fail, потом unknown. pass не показываются.

Обоснование решений:

- Никаких процентов совпадения. Условия правомочности не складываются, а
  умножаются: если недостающие 15 процентов — это гражданство, то 85 равны нулю.
- Сообщения собираются в коде из чисел по шаблону на поле, а не хранятся в
  данных. Иначе это 210 строк, которые разъедутся с данными за месяц.
- Отсутствие поля в профиле тоже даёт unknown, но с другим текстом: «программа не
  указывает требование» и «ты не указал» — разные ситуации.
- Возраст считается на deadline.closes с учётом asOf. Если дедлайн expected,
  пограничный возраст даёт unknown, а не pass.
- GPA: конвертация шкал приблизительна. Если пересчитанный балл ближе к порогу,
  чем на 5 процентных пунктов, результат unknown с пояснением. Вид точности там,
  где точности нет, хуже её отсутствия.
- Язык: сертификата нет — unknown, экзамен можно сдать. fail только если
  сертификат есть и балл ниже порога.
- textConditions не влияют на цвет. Они есть почти у каждой программы; если
  каждое красит в жёлтый, жёлтыми становятся все карточки и светофор перестаёт
  различать. Условия показываются отдельным списком «проверь сам». Цена решения
  названа прямо: такое условие не отсеет человека автоматически.
- Дедлайн в вердикте не участвует. Он отдельный признак карточки: приём открыт,
  откроется примерно тогда-то, закрыт. Не пройти по возрасту и опоздать — разные
  вещи. Закрытая программа уезжает вниз списка, а не краснеет.

## 6. Сборщик данных

```
sources.yaml     человек вписывает id программы и утверждённые URL
  -> fetch.py    скачивает, кладёт снимок в raw/<id>/<дата>/, считает sha256
  -> extract.py  модель читает снимок, пишет в proposed/<id>.json
  -> validate.py механические проверки, без модели
  -> review.py   человек утверждает поле за полем
  ->             утверждённое ложится в data/programs/<id>.json
  -> build.py    собирает data/index.json
check.py         перекачивает источники, сравнивает хеши, помечает stale
```

Обоснование решений:

- Шаги разорваны, потому что ненадёжен ровно один — извлечение моделью. Разрыв
  позволяет перезапустить извлечение на том же снимке и сравнить два прогона.
  Расхождение на одном тексте — сигнал заполнять поле руками.
- У процесса извлечения нет пути записи в data/programs/. Туда пишет только
  review.py после подтверждения человеком. Правило «человек утверждает, робот
  собирает» держится на структуре, а не на договорённости.
- Источники утверждает человек. Автоматический поиск через поисковик отвергнут:
  SEO-мусор и агентские сайты ранжируются выше первоисточников.
- Официальные домены вузов берутся из Wikidata, свойство P856.

### validate.py

- Проверка цитат: каждое evidence обязано быть дословной подстрокой скачанного
  снимка. Механический детектор галлюцинаций: придуманное требование не получит
  цитату, которая найдётся поиском.
- Обязательные поля: eligibility.citizenship и eligibility.graduationYear не
  могут быть null. Запрещено именно «не знаем»; разрешены и правило с цитатой,
  и подписанное человеком noLimit. Программа без них не публикуется.
- Проверка подписи: при noLimit цитата обязана быть null, checkedBy равен
  human, checkedAt — дата, note не пустая, и ни одного ключа со значением.
- Связность: closes позже opens, age.max в диапазоне 15–60, коды стран
  существуют, id совпадает с именем файла, scale из известного списка.

### check.py

Частота вычисляется из deadline.closes: ближе 30 дней — ежедневно, 30–90 —
еженедельно, дальше — ежемесячно. В v1 запускается вручную. GitHub Actions —
после того, как инструмент заработает.

### Про зависимости

Правило было «ноль зависимостей». С 4 сентября 2026 оно звучит точнее:
**ноль зависимостей у сайта, минимум у сборщика.**

Причина — PDF. Половина государственных стипендий публикует настоящие
требования не на странице, а в приложенном документе: Stipendium Hungaricum,
MEXT и другие. Без чтения PDF они недоступны конвейеру целиком, а прочитать
PDF стандартной библиотекой нельзя.

Зависимость одна — `pypdf`, чистая на Python, без компиляции, только в
`tools/`. Сайт по-прежнему не имеет ни одной: PDF читается при сборке
данных на машине автора, а не у пользователя в браузере.

### Чего сборщик не умеет

Он читает HTML как есть и не выполняет JavaScript. Сайт, который рисует
содержимое приложением в браузере, даёт пустой снимок: ноль символов текста,
проверять цитаты не по чему.

Это не теоретическое ограничение. Портал российской квоты
`education-in-russia.com` — ровно такой случай: 5392 символа HTML и ноль
символов текста. Как источник в нынешнем виде он непригоден, хотя программа
для аудитории инструмента одна из самых важных.

Обход требует headless-браузера, то есть тяжёлой зависимости, а правило
проекта — ноль зависимостей. Поэтому пригодность сайта проверяется **до**
утверждения домена, а не после: скачать главную и посмотреть, сколько текста
из неё извлекается.

Проверено 3 сентября 2026: `turkiyeburslari.gov.tr` — 6905 символов текста,
`studyinkorea.go.kr` — 10942, `stipendiumhungaricum.hu` — 3079. Все три
годятся. `campuschina.org` не разрешается по DNS.

### raw/

Коммитится извлечённый текст страниц и PDF. Оригинальные PDF — только меньше
мегабайта, иначе хватает хеша и ссылки. Текст нужен, чтобы проверка цитат
работала не только в момент скачивания, но и через полгода, когда кто-то
спросит, откуда взялось число.

## 7. Раскладка репозитория

```
index.html
css/style.css
js/
  profile.js     форма, localStorage
  rules.js       семь функций правил
  verdict.js     сборка трёх состояний
  render.js      список и карточка
  main.js        связка
data/
  index.json     генерируется, лежит в git
  programs/*.json
tools/
  sources.yaml
  fetch.py extract.py validate.py review.py build.py check.py
  schema/program.schema.json
raw/
proposed/     не коммитится, выход модели до утверждения
tests/
README.md
```

rules.js не знает про HTML, render.js — единственный, кто трогает DOM. Это
условие того, что правила можно переписать руками и объяснить построчно.

## 8. Тесты

Только rules.js и verdict.js. Обязательные случаи: пограничный возраст на день
дедлайна, null в каждом из семи полей, GPA в полосе неопределённости, язык без
сертификата, deny по гражданству. DOM не тестируется.

## 9. Границы v1

Целевой размер v1 по правилам проекта — 25–30 программ. Но выпуск не ждёт их
всех: первый работающий выпуск — десять государственных программ, дальше набор
пополняется на уже живом инструменте. Причина: десять государственных записей
покрывают сотни вузов, и инструмент из них уже полезен, а сборка тридцати до
первого запуска откладывает проверку на реальных людях на месяцы.

Готово, когда:

1. Десять государственных программ собраны, у каждой humanChecked true, цитаты
   проходят проверку подстрокой.
2. Форма из семи полей, профиль переживает перезагрузку.
3. Три вердикта с причинами по-русски.
4. Тесты правил проходят.
5. Опубликовано на GitHub Pages, работает с телефона.
6. README объясняет, откуда данные и как их перепроверить.

Не входит в v1: поиск, фильтры, сравнение программ, тёмная тема, таджикский язык
интерфейса, программы сверх первой десятки.

Приоритет наполнения: государственные программы прежде отдельных университетов —
одна запись покрывает десятки вузов. Региональные программы прежде мировых.

### Ограничения производительности

Ноль внешних библиотек, ноль подключаемых шрифтов, index.json не больше 100 КБ,
полный JSON программы догружается при открытии карточки. Цель — открытие за
секунду на мобильном интернете.
