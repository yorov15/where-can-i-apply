# Следующий этап Nerio: факты для заявки и снятие взносов

Основание: продолжение работы по поручению Мурода 05.11.2026. Предыдущий выпуск не закрывает всю большую задачу переноса полезных функций подготовительных платформ.

1. Банк историй внутри подготовки и эссе: шесть вопросов, собственные случаи, действия, результат, вывод и назначение; начало из существующего опыта без изменения исходной записи. Локальное хранение, редактирование, копирование, удаление с подтверждением, общий экспорт/импорт. До 20 историй.
2. Сведения о школе: необязательные поля, исходная шкала без пересчёта GPA, двуязычные подписи, печать/PDF и копирование после сохранения. Это черновик со слов ученика для подтверждения школой, не официальный документ.
3. Снятие взноса за заявку: проверить первоисточники на уже разрешённых доменах, выделить подтверждённые условия рядом со взносом; не путать со снятием платы за обучение. Не обещать доступность иностранцам без цитаты. Шаблон запроса только там, где уместен.

Приёмка: совместимость прежнего файла, перенос новых записей, отказ хранилища без ложного сохранения, сохранность ввода при медленной сети, печать, клавиатура, 375/1280 обе темы, оба набора тестов и сборка. Недоступные источники и предел охвата явно записать. Проверку на учениках, Safari/iPhone и физическом принтере не выдавать за выполненную.
