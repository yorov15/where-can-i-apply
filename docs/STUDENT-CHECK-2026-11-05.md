# Проверка Nerio с 2–3 учениками

На каждого участника: 10–15 минут. Желательно один iPhone/Safari и один Android. Используйте отдельный тестовый профиль браузера или вымышленные сведения: личные данные для этой проверки не нужны.

В начале скажи: «Мы проверяем сайт. Если что-то непонятно, это замечание к сайту, а не к тебе. Говори вслух, что ищешь и почему нажимаешь сюда». Покажи https://nerio-app.vercel.app/ и не объясняй кнопки заранее.

| Задание | Что наблюдать |
|---|---|
| Найди программу и объясни, можно ли сейчас подаваться | Замечает ли срок, различает ли допуск и вероятность приёма, находит ли источник |
| Начни одну посильную работу и найди первый шаг | Понимает ли ожидаемый результат, где работать и как сохранить результат шага |
| Найди конкретную идею и измени её вопрос под себя | Может ли объяснить, что получится и как проверить результат |
| Сохрани короткую историю для эссе | Находит ли раздел, понимает ли разницу между случаем и общим заявлением о себе |
| Скачай резервную копию и объясни, что будет при смене телефона | Понимает ли локальное хранение и назначение файла |

Для iPhone отдельно проверь: поля не выходят за экран, клавиатура не закрывает сохранение, переход назад сохраняет ввод до перезагрузки, можно скачать файл и открыть меню печати/PDF. Для проверки переноса сначала сохрани копию: загрузка файла заменяет текущие записи.

Если есть принтер: вымышленные сведения о школе → сохранить → печать. Сверь имя школы, шкалу, перенос длинного текста, поля и отсутствие элементов навигации на листе. Запиши, какой браузер и принтер использованы. PDF без физической печати не отмечай как проверку принтера.

После каждого задания спроси: «Что ты ожидал увидеть после нажатия?» В конце: «В каком месте пришлось угадывать? Что из этого пригодилось бы тебе на этой неделе?» Не подсказывай ответ и не заменяй наблюдение оценкой «нравится/не нравится».

## Лист наблюдений

Не записывай полное имя. Достаточно «участник 1», класса, устройства и браузера.

| Участник / устройство | Задание | Самостоятельно / с подсказкой / не получилось | Дословная короткая реплика | Где остановился | Возможная правка |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |
| | | | | | |

Сначала исправляйте потерю данных, неверно понятые сроки и места, где невозможно продолжить. Затем — повторившуюся у двух участников непонятную кнопку или формулировку. Один комментарий о вкусе пока оставьте заметкой.

**Статус:** сценарий подготовлен. Настоящие ученики, Safari на iPhone и физическая печать ещё не проверены; результаты здесь не вымышлялись.
