# Факты для заявки и снятие взносов — 05.11.2026

Следующий этап после PR #7, база `2964037`. Поручение Мурода: продолжать большую задачу переноса полезных функций подготовительных платформ. Этот этап закрывает банк историй, сведения о школе и первую проверенную партию условий снятия взносов. Весь список развития этим не закрыт.

## Поведение

- «Мой путь → Подготовка» даёт вход в банк историй и сведения о школе даже без выбранного вуза. Банк также доступен из эссе и «Моих работ». Шесть вопросов помогают вспомнить случаи; до 20 историй с контекстом, собственными действиями, результатом, выводом и назначением. Можно начать из опыта: исходная работа не меняется, история сохраняет свой снимок фактов. Есть редактирование, копирование и удаление с подтверждением.
- Школа: десять необязательных полей, исходная шкала без пересчёта GPA, двуязычные подписи, копирование, печать/PDF и удаление с подтверждением. На листе явно написано, что это черновик ученика для подтверждения школой. Кнопки экспорта ждут сохранения. Ctrl+P с несохранённым вводом печатает предупреждение и только прежнюю сохранённую версию, если она есть.
- Сохранённые истории и школа входят в прежний файл маршрута v2; пустой раздел не добавляется. Неизвестная версия или повреждённый новый раздел отклоняет импорт целиком, чтобы не терять личные записи молча. Несохранённый ввод переживает переходы по сайту до перезагрузки. Отказ хранилища оставляет форму на месте и не выдаёт успех.

## Снятие взносов

Восемь официальных страниц повторно получены напрямую 05.11.2026; цитаты проверены по полученному тексту, короткие выдержки и их UTF-8/LF SHA-256 сохранены в `raw/fee-waivers/`, хеш HTTP-ответа — в данных. Условия проверены отдельно от прочих правил вузов: их старые даты проверки не обновляются.

| Программа | Подтверждённое действие | Аудитория в записи |
|---|---|---|
| Bowdoin | Автоматически при указании запроса помощи | Иностранцы явно названы |
| WashU | Отметить право на waiver в заявке, вуз проверяет его | Любой заявитель на помощь по нужде |
| Wesleyan | Предлагается всем заявителям на финансовую помощь | Все заявители; процедура подробно не описана |
| Caltech | Форма Active Transport Pass при запросе помощи и тяжёлом взносе | Отдельное правило для иностранцев не подтверждено |
| CMU | Признаки финансовой нужды Common Application | Отдельное правило для иностранцев не подтверждено |
| NYU Shanghai | Запрос при невозможности оплатить | Отдельное правило для иностранцев не подтверждено |
| Emory | Запрос онлайн через Common Application | Отдельное правило для иностранцев не подтверждено |
| University of Washington | Снятие взноса недоступно иностранцам первого курса | Иностранцы явно названы |

Для неподтверждённой аудитории карточка просит уточнить применимость до оплаты. Текст вопроса на английском содержит места для страны и имени, не выдумывает доход или нужду семьи и сам ничего не отправляет. При автоматическом снятии или запрете такой шаблон не показывается. Условия старше 60 дней получают предупреждение. Остальные программы не объявляются проверенными.

Исправлен расчёт: у NYU Shanghai прежнее `waivedForAid` не означало автоматическое снятие; запрос больше не вычитает 85 USD из расходов. То же консервативное правило применяется к другим записям с режимом request. Снятие платы за обучение не подменяет снятие взноса за заявку.

Мурод одобрил новый официальный домен WashU ответом «Да, подключи admissions.washu.edu»; точная запись в `tools/fee-waiver-sources.json`. Прежний `admissions.wustl.edu` перенаправляет туда. Другие домены сверены с реестром данной программы `tools/sources.toml`. Сборка отклоняет неодобренный домен, подмену цитаты/хеша, выход пути снимка, неверную аудиторию или будущую дату проверки.
