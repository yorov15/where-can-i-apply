`save_snapshots`, те же хеши). Так сделан `ecnu`; остальные files-секции работают на
старых снимках, потому что их сайты из этой сети недоступны (umich.edu, nyu.edu,
utoronto.ca, ntu.edu.tw, uzh.ch, ac.uk — 000/403).
