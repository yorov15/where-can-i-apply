# Следующий набор у закрытого приёма — 04.11.2026

Ветка `claude/next-round`, в `main` не влито, не выложено.

## Можно ли по правилам

Правило в `AGENTS.md`: «Нет даты на странице — срок `null`». Оно про данные: в `data/` нельзя
записать дату, которой нет в источнике. Оценку интерфейса оно не запрещает. Для оценок есть
отдельное правило: «Оценки … — только с пометкой „оценка“ и источником». Строка говорит
«≈ … — по прошлому году, сверь на сайте программы»: знак и слова помечают догадку, источник —
прошлогодняя дата программы. В `data/` ничего не пишется.

## Что уже было

Почти всё сделано раньше в `claude/catalog-deadlines` (влито и выложено 04.11.2026): `nextIntake`
в `js/lib/deadline.js` и строка «Приём закрыт. Следующий набор ≈ <месяц год> — по прошлому году,

нечем.

## Что сделал

1. **Оценка по `opens`.** Если программа называла начало приёма, следующий набор считается по нему
   (месяц `opens` + 1 год), иначе по `closes`. Если месяц открытия через год уже прошёл, а месяц
   срока ещё нет, берётся срок. Прошли оба — оценки нет, остаётся «Приём закрыт <дата>».
   Из 33 закрытых программ у 17 есть `opens`. Например, СПбГУ (12.11.2025–06.02.2026): было
   «≈ февраль 2027», стало «≈ ноябрь 2026»; ITU (24.04–26.06.2026): было «≈ июнь 2027», стало
   «≈ апрель 2027».
2. **Одна формулировка.** `nextIntakeLine` в `js/lib/format.js` — единственное место с текстом
   оценки.
3. **«Мой путь» и маршрут.** Раньше там была только старая дата. Теперь:
   - строка цели во вкладке «Заявки» — «Приём закрыт. Следующий набор ≈ …»;
   - шаг подачи (вкладка «Подготовка») — заголовок прежний «Приём закрыт <дата>», оценка в
     пояснении. Заголовок не менял: от него зависит id шага и сохранённые галочки;
   - текст для родителя (`routeText`) — «Срок: приём закрыт <дата>. Следующий набор ≈ …».
   Для этого у `goal.deadline` появилось поле `next` (готовая строка или `null`).
4. **Сортировка «по сроку»** не менялась: открытые по дате, потом закрытые по дате закрытия,
   в конце программы без срока. Поправил только комментарий в `js/filter.js`.
