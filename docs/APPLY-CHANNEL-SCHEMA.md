# Пилот «Как подавать»: схема до сбора данных

28.10.2026, ветка `redesign-v2`. На момент публикации этого предложения данные программ не внесены, интерфейс не изменён. Схема и механическая валидация добавлены первыми.

```json
{
  "applyChannel": {
    "routes": [
      {
        "type": "university",
        "name": "Название портала из источника",
        "url": "https://example.edu/apply",
        "note": "Назначение этапа или условия этого пути",
        "evidence": "Дословная цитата",
        "source": {
          "url": "https://example.edu/admissions",
          "lastVerified": "2026-10-28",
          "contentHash": "sha256:<64 шестнадцатеричных знака>"
        }
      }
    ]
  }
}
```

`type`: `university` — сам вуз, `platform` — общая платформа, `government` — государственный портал, `embassy` — посольство, `school` — номинация школой, `agent` — названный вузом агент/его официальная сеть.

Почему список: вуз может разрешать и прямую подачу, и агента; стипендия может требовать сначала номинацию школой, затем заявку. Нельзя молча превратить один из таких путей в единственный. Отдельная `note` сохраняет назначение и ограничения каждого пути. Список не означает автоматически «или» или «затем».

Поле необязательное. Если канал прямо не назван, `applyChannel` не вносится (допустим также null), причина остаётся в отчёте; строки на экране нет. У подтверждённого поля — 1–6 маршрутов. Все поля маршрута обязательны; `note` может быть пустой при наличии URL. Для офлайн-подачи, номинации, персональной ссылки по email или адресата, зависящего от выбранного вуза, URL может быть null, но пояснение обязательно. Не придумываем единый адрес портала посольства или школы.

У каждого маршрута собственные цитата, URL источника, дата и SHA-256 UTF-8 снимка. Для ссылок снимок сохраняет также извлечённые href исходной страницы. Источник должен использовать HTTPS. URL портала сохраняет HTTP(S), как в исходной ссылке; HTTPS не угадываем. Валидация проверяет типы, допустимые значения, безопасные схемы URL, наличие цитаты и ссылки в снимке, дату и форму хеша; независимая проверка файлов сверяет фактические байты и хеш до внесения.

Канал попадёт только в лёгкие детали программы, без увеличения индекса каталога и без фильтра. На экране — одна дополнительная строка «Как подавать: …» в блоке фактов, с ссылкой на названный портал; несколько подтверждённых путей перечисляются в той же строке. Порядок этапов, ограничения, источники и даты — в раскрываемом блоке по кнопке «Порядок и условия».

План выборки: 30 программ разных стран; минимум по 3–4 кандидата на прямую подачу, общие платформы, государственные порталы, посольство/номинацию школой и агентов. Фактические типы определит источник. Неподтверждённый тип не будет назначен ради квоты.

Время исследования и внесения измеряется отдельно от реализации/тестов. Среднее — календарное время партии / 30, с явным указанием параллельных загрузок.
