## Что сделано

1. **Формат итога учебной работы.** При создании работы есть поле «В каком виде будет итог?»: текст, приложение или код, расчёт или таблица, выступление или видео, другое. По умолчанию его подставляет шаблон (данные → расчёт или таблица, прототип → приложение или код, творческая → другое, жизненный опыт → текст); ученик может выбрать другой. В открытой карточке работы — строка «Итог: <формат> — <ожидаемый результат>». Формат можно поменять в «Уточнить задачу и объём». Поле `workPlan.format`, список `WORK_FORMATS` в `js/portfolio-work.js`.
2. **Навыки у записи опыта.** В форме опыта — до трёх навыков из закрытого списка: самостоятельность, лидерство, работа в команде, исследование, творчество, помощь людям, техника. После трёх отметок остальные варианты блокируются. В карточке — строка «Навыки: …». Поле `experience.skills` хранится только если не пустое; список `EXPERIENCE_SKILLS` в `js/portfolio.js`.
3. **«Примеры по навыку» на экране эссе** (`#route/preparation`, раздел «Эссе и мотивационные письма»). Свёрнутый блок: свои записи, сгруппированные по навыкам в порядке списка, каждая — ссылка, открывающая запись в «Работах». Если навыки нигде не отмечены, блок подсказывает, где их отметить.
4. **Счётчик у вопроса эссе.** Счётчик уже был. Он вынесен в чистую функцию `essayCount` (`js/essay.js`) и стал точнее: «22 из 300 знаков», если граница есть в данных программы; «Пока меньше минимума» при нижней границе слов; байты показываются, только если программа задаёт лимит в байтах; склонение «1 слово / 3 слова». Границы берутся только из полей `words`/`characters`/`bytes` в `data/prep/<id>.json`, а `tools/essays.py` при сборке сверяет их с цитатой из снимка. Нет поля — счётчик без границы. Данные эссе не менялись, новые лимиты не добавлялись. Сейчас границы есть у 4 из 11 программ с эссе: KAIST, AUCA, ICU, Tohoku.
