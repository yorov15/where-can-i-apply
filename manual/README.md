# Файлы, сохранённые человеком

Сюда кладутся страницы и документы, которые конвейер скачать не может, а
человек — может. Шесть причин, все встречались:

- сайт рисует содержимое JavaScript-ом, и в HTML пусто (портал российской квоты);
- сервер отдаёт 412 автоматическим клиентам (китайские порталы);
- документ спрятан за формой или входом;
- сайт не открывается из сети, где работает конвейер: индийские
  государственные сайты (iccr.gov.in, eoidushanbe.gov.in) отдают таймаут
  на каждой попытке, хотя снаружи открываются.
- сервер обрывает TLS-рукопожатие у Python, хотя curl и браузер проходят
  (sos.sejong.ac.kr, en.sejong.ac.kr, wwwe.sogang.ac.kr): гид Sejong и
  страница требований Sogang скачаны обычным curl.
- сервер отдаёт PDF только со страницы, на которой лежит ссылка, и отвечает
  403 тому, кто пришёл по прямой ссылке (защита от hotlink): два PDF Waseda
  — список документов и гид SILS — открываются из браузера по клику со
  страницы `waseda.jp/inst/admission/en/undergraduate/english/`, а сборщик
  Referer не шлёт. Файлы лежат в `manual/waseda/`.
- документ лежит не на сайте вуза, а на Google Drive, и сборщик его не
  берёт: правила приёма Tsukuba Interdisciplinary Engineering —
  `manual/tsukuba-ide/guidelines.pdf`.

## Это не обход защиты

Страницу открывает человек, своим браузером, обычным способом. Конвейер
лишь разбирает файл, который уже получен. Притворяться браузером, чтобы
пройти чужую защиту, проект не делает.

## Как добавить

1. Открой страницу или документ сам и сохрани файл сюда, в папку с
   именем программы: `manual/<program-id>/<имя файла>`.
2. Впиши в `tools/sources.toml`:

```toml
[program-id]
name = "Название программы"
files = [
  { path = "manual/program-id/rules.html", url = "https://официальный-сайт/страница" },
]
approvedBy = "human"
approvedAt = "ГГГГ-ММ-ДД"
```

Адрес `url` обязателен, даже когда файл лежит рядом: без него запись
нельзя перепроверить, а это главное обещание проекта. Дальше всё как
обычно — `fetch`, `extract`, `review`, `build`.

## Что меняется в слежении

`check.py` такой источник перекачать не может и не пытается. Срок
проверки считается так же, по близости дедлайна, но вместо сравнения
хешей он скажет: «источник ручной — пересохрани файл». Дальше твоя
работа.

## Почему сами файлы не в git

Оригиналы могут весить мегабайты, а хранить их незачем: извлечённый
текст лежит в `raw/` с датой и хешем, и именно по нему проверяются
цитаты. Оригинал нужен ровно один раз — в момент, когда ты его
сохранил и запустил `fetch`.
