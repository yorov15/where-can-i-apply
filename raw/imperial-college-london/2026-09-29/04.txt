August 2027 (date to be confirmed) - A-level results published Admissions tests deadlines We use admissions tests as part of the application process for many of our courses. The test you could need to take for your application depends on which course you're applying for. You can find out if your course requires an admissions test as part of the application process on relevant course pages. Admissions tests deadlines for 2026 entry Engineering and Science Admissions Test (ESAT) Test of Mathematics for University Admissions (TMUA) Graduate Medical School Admissions Test (GAMSAT) University Clinical Aptitude Test (UCAT) Engineering and Science Admissions Test (ESAT) There are two test sittings for the ESAT for 2027 entry: one in October 2026 and one in January 2027. Candidates in most countries can book a time slot on any day within the test windows, though please note that those taking the test in China, Hong Kong, or Macau can only do so on specific dates within each window. These are listed separately below. For candidates in all countries except China, Hong Kong and Macau Test window 1: 12-16 October 2026 Test window 2: 4-8 January 2027 For candidates sitting the test in China, Macau and Hong Kong Test window 1: 12-13 October 2026 Test window 2: 6 January 2027 Booking windows (all candidates) Test window 1: 20 July-28 September 2026 (UK time) Test window 2: 26 October-21 December 2026 (UK time) For more details, please visit the UAT-UK website . More information Learn about the ESAT, including test format, how to book and prepare for this test on the Engineering and Science Admissions Test (ESAT) web page or head to the UAT-UK website for more information. Test of Mathematics for University Admissions (TMUA) There are two test sitting windows for the TMUA for 2027 entry: one in October 2026 and one in January 2027. Candidates in most countries can book a time slot on any day within the test windows, though please note that those taking the test in China, Hong Kong, or Macau can only do so on specific dates within each window. These are listed separately below. For candidates in all countries except China, Hong Kong and Macau Test window 1: 12-16 October 2026 Test window 2: 4-8 January 2027 For candidates sitting the test in China, Macau and Hong Kong Test window 1: 15-16 October 2026 Test window 2: 8 January 2027 Booking windows (all candidates) Test window 1 Booking opens: 20 July 2026 at 15.00 (UK time) Booking closes: 28 September 2026 at 18.00 (UK time) Test window 2 Booking opens: 26 October 2026 at 15.00 (UK time) Booking closes: 21 December 2026 at 18.00 (UK time) More information Learn about the TMUA, including test format, how to book and prepare for this test on the Test of Mathematics for University Admissions (TMUA) web page or head to the UAT-UK website for more information. Graduate Medical School Admissions Test (GAMSAT) You need to take either the UCAT or GAMSAT if you are applying to our Medicine (Graduate Entry) course. More information Learn about the GAMSAT on the Graduate Medical School Admissions test official website . University Clinical Aptitude Test (UCAT) You need to take the UCAT if you are applying to our 6-year MBBS Medicine (Standard course A100). You need to take either the UCAT or GAMSAT if you are applying to our Medicine (Graduate Entry) course. Account registration opens on Tuesday 12 May 2026. Booking opens on Tuesday 23 June 2026. Testing starts Monday 13 July 2026 and ends Thursday 24 September 2026. More information Learn about the UCAT, including how to register and prepare for this test on the University Clinical Aptitude Test (UCAT) web page or head to the UCAT website for more information. Offer condition deadlines If we make you an offer, you will need to have fulfilled all conditions before the relevant deadline. For more information, see submitting your offer conditions .
