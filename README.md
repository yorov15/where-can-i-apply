# Куда я могу подать документы

Инструмент показывает школьнику из Центральной Азии, в какие программы
обучения за рубежом он может подать документы, в какие не может и по
какой именно причине. Правомочность проверяется на уровне программы, а
не университета: одна запись покрывает десятки вузов сразу.

## Откуда данные

Каждое поле каждой записи берётся с официального сайта программы и
хранится вместе с дословной цитатой из источника, ссылкой, датой
проверки и хешем страницы. Ничего не пишется по памяти.

Проверить любое число можно так: открыть `data/programs/<id>.json`,
взять поле `evidence` рядом с интересующим значением и найти эту фразу
на странице по адресу из `source.url`.

Если цитата на странице не находится — это ошибка, и её надо чинить.

## ИИ-объяснение (необязательно)

Кнопка «Объяснить простыми словами» в карточке просит Claude пересказать
причины ответа живым языком: почему нельзя, как обойти, что сделать.
Пока `EXPLAIN_URL` в `js/config.js` равен `null`, кнопки нет, сайт не
делает ни одного запроса наружу и работает как раньше.

Как включить:

1. Развернуть репозиторий на Vercel: `api/explain.js` станет функцией
   `/api/explain`, `vercel.json` уже настроен.
2. В Vercel → Settings → Environment Variables задать `ANTHROPIC_API_KEY`.
   Ключ не должен попадать ни в репозиторий, ни в браузер.
3. В консоли Anthropic поставить месячный лимит трат: счётчики в самой
   функции держатся в памяти и защищают лишь от случайного перебора,
   настоящий потолок расходов — только лимит в консоли.
4. Вписать адрес в `js/config.js`: `'/api/explain'`, если сайт стоит там же,
   иначе полный адрес и `ALLOWED_ORIGINS` в Vercel.

Необязательно: `EXPLAIN_MODEL` (по умолчанию `claude-opus-5`; дешевле —
`claude-haiku-4-5`), `DAILY_LIMIT` (обращений к модели в сутки, по
умолчанию 300).

**Что уходит наружу:** только код каждой причины ответа по одной
программе и числа, названные в ней (например, порог IELTS). Анкета
целиком, дата рождения и профиль не отправляются. Тексты причин и
условия программы собираются на сервере из тех же файлов, что и на
сайте, поэтому модель говорит только то, что записано в карточке и
подтверждено цитатой. Одинаковые вопросы обслуживаются из кэша.

## Зависимости

**У самого сайта их нет ни одной.** Он читает готовые `data/index.json` и
`data/details.json` и работает из любой папки без сборки. Единственная
зависимость репозитория — `@anthropic-ai/sdk`, и нужна она только
функции `api/explain.js`.

```bash
npm install
```

У сборщика данных одна — `pypdf`, для чтения PDF: половина
государственных стипендий публикует требования не на странице, а в
приложенном документе. Она нужна только тому, кто собирает данные.

```bash
python -m pip install -r tools/requirements.txt
```

## Дисклеймер

Инструмент не заменяет сайт программы. Жёлтый вердикт означает, что
условие проверить не удалось, а не что оно выполнено.
