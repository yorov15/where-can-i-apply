# Куда я могу подать документы

Инструмент показывает школьнику из Центральной Азии, в какие программы
обучения за рубежом он может подать документы, в какие не может и по
какой именно причине. Правомочность проверяется на уровне программы, а
не университета: одна запись покрывает десятки вузов сразу.

## Откуда данные

Каждое поле каждой записи берётся с официального сайта программы и
хранится вместе с дословной цитатой из источника, ссылкой, датой
проверки и хешем страницы. Ничего не пишется по памяти.

Проверить любое число можно так: открыть `data/programs/<id>.json`,
взять поле `evidence` рядом с интересующим значением и найти эту фразу
на странице по адресу из `source.url`.

Если цитата на странице не находится — это ошибка, и её надо чинить.

## Как запустить у себя


## ИИ-объяснение (необязательно)

Кнопка «Объяснить простыми словами» в карточке просит языковую модель
пересказать причины ответа живым языком: почему нельзя, как обойти, что
сделать. Пока `EXPLAIN_URL` в `js/config.js` равен `null`, кнопки нет, сайт
не делает ни одного запроса наружу и работает как раньше.

Модель бесплатная, через OpenRouter (`api/explain.js`, обычный `fetch`,
без зависимостей). Моделей шесть, они пробуются по одной: Gemma 4 31B и 26B, Qwen3.8 27B,
DeepSeek V4 Flash, Nemotron 3 Super и `openrouter/free`. Каждый ответ
проверяется перед показом (начинается с заголовка «Почему так», написан
по-русски): занятая или болтливая модель, которая вместо ответа выдала
черновик, уступает место следующей. Ошибка появляется, только когда не
подошла ни одна. Когда сайт станет популярным, в `EXPLAIN_MODELS` можно
поставить платную (например, DeepSeek).

Как это устроено на Vercel:

1. Проект на Vercel собирается из этого репозитория: сайт остаётся
   статичным, `api/explain.js` становится функцией `/api/explain`.
2. В Vercel → Settings → Environment Variables задаётся
   `OPENROUTER_API_KEY`. Ключ не должен попадать ни в репозиторий, ни в
   браузер.
3. Когда функция отвечает, в `js/config.js` вписывается `'/api/explain'`.

Необязательно: `EXPLAIN_MODELS` (до трёх моделей через запятую),
`DAILY_LIMIT` (обращений к модели в сутки на экземпляр функции, по
умолчанию 40 — у бесплатных моделей OpenRouter свой суточный предел),
`ALLOWED_ORIGINS` (если сайт стоит не там же, где функция).

**Что уходит наружу:** только код каждой причины ответа по одной
программе и числа, названные в ней (например, порог IELTS). Анкета
целиком, дата рождения и профиль не отправляются. Тексты причин и
условия программы собираются на сервере из тех же файлов, что и на
сайте, поэтому модель говорит только то, что записано в карточке и
подтверждено цитатой. Одинаковые вопросы обслуживаются из кэша. Бесплатные
модели OpenRouter могут сохранять запросы, поэтому в них не должно быть
ничего личного — и нет.

## Зависимости

**У сайта и у функции их нет ни одной.** Он читает готовые
`data/index.json` и `data/details.json` и работает из любой папки без
сборки.

У сборщика данных одна — `pypdf`, для чтения PDF: половина
государственных стипендий публикует требования не на странице, а в
приложенном документе. Она нужна только тому, кто собирает данные.

```bash
python -m pip install -r tools/requirements.txt
```

## Дисклеймер

Инструмент не заменяет сайт программы. Жёлтый вердикт означает, что
условие проверить не удалось, а не что оно выполнено.
